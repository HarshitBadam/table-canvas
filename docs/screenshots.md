# Product screenshots

A visual tour of Table Canvas using a populated project.

## Workbook import

![Excel workbook sheet selection with eight sheets ready to import](screenshots/workbook-import.png)

Inspect an Excel workbook, review every available sheet and row count, then choose which tables to add to the project.

## Visual pipeline

![Canvas containing source tables, derived tables and a linked chart](screenshots/canvas-pipeline.png)

Source tables feed joined and summarized results, while the linked chart remains part of the visible transformation lineage.

## Combine tables

![Join configuration with matching columns and a match-rate preview](screenshots/combine-tables.png)

Join or append two tables, select the matching columns and output fields, and review the match rate before creating the derived result.

## Table view

![Editable source table with typed columns and spreadsheet controls](screenshots/table-view.png)

Edit typed source data in a virtualized spreadsheet with dedicated row, column, filter, chart, and suggestion controls.

## Suggestions panel

### Analysis recommendations

![Expanded analysis recommendation for a stock trend chart](screenshots/suggestions-analysis.png)

Profile-driven recommendations explain why an analysis fits the table and can create the resulting chart directly.

### Batch cleaning

![Batch cleaning review with eight selected data-quality fixes](screenshots/suggestions-cleaning.png)

Cleaning suggestions show affected values and combine compatible fixes into one reviewable action.

## Chart editor

![Rendered stock chart with chart type, axes and aggregation controls](screenshots/chart-editor.png)

Switch between bar, line, pie, and scatter charts while configuring the source, axes, measure, and aggregation against live project data.

## Project dashboard

### Overview and lineage

![Project dashboard with workspace totals and a transformation lineage map](screenshots/dashboard-overview.png)

Workspace totals and completeness sit beside a compact data-flow map of source tables, derived tables, and charts.

### Data health and next actions

![Project dashboard showing derived-table health and suggested actions](screenshots/dashboard-actions.png)

Table-level health checks and suggested analyses turn the dashboard into an actionable project overview.

## Report builder

![Report editor with formatted analysis, a live chart and the block insertion menu](screenshots/report-builder.png)

Compose formatted analysis around live project data, then insert charts, linked tables, editable tables, callouts, and collapsible sections.

## Project portability

![Project import and export menu over a populated canvas](screenshots/project-portability.png)

Export a self-contained ZIP with project state, Excel data, and reports, or import a saved Table Canvas project without requiring an account.
